# Agent entrypoint

O código e a documentação deste repositório são a autoridade para builds, versões e compatibilidade com OBS. Antes de alterar, confira a branch, o diff e as instruções locais.

Para contexto anterior ou decisões compartilhadas, consulte **sob demanda** o `angelo-vault` autorizado (resolvido por `AI_VAULT_PATH`) e `Runbooks/agent-context-efficiency.md`. Não carregue o vault inteiro, nem suponha que ele esteja acessível. Prefira busca direcionada, trechos de logs e testes pertinentes; preserve verificações obrigatórias.

Este plugin mantém os destinos configurados manualmente; não reintroduza o hub de contas sem nova decisão. Não publique binários ou releases sem validar os artefatos.
